# Additional scientific packages (pandas, numpy, xarray, netCDF4, etc.) are
# intentionally NOT pre-baked into this image - the agent installs what a
# given task needs on demand via run_terminal_tool ("pip install ..."),
# same as the existing sandbox_service shell backend already does. Baking
# in the full scientific stack would bloat every user's VM image for
# packages many sessions never use.
